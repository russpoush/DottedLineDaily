# Dotted Line Daily

**Spot the traps before you sign.** Each day there's one realistic document: a lease, a car loan, a hospital bill, a job offer, a phone deal. You tap the clauses you'd push back on, then see what each trap would cost you and exactly what to say.

**Play:** https://russpoush.github.io/DottedLineDaily/

## What's in it
- 30 cases (85 traps) across Everyday, Housing, Money, Health and Work, with a new case each day.
- Normal clauses that look suspicious, so tapping everything doesn't win.
- A dollar cost and a word-for-word script for every trap.
- Expert rounds after the first cycle, with the trap count hidden.
- Streaks and a "money you'd have kept" tally, saved in your browser.

## Status
This is a prototype for testing. "Pro" is a preview only, and no payment is taken.

The documents and companies are fictional. The explanations are general education, not legal or financial advice. Rules vary by state, and a professional hasn't reviewed the content yet. Each batch of cases is fact-checked by a separate reviewer before it's published.

"Dotted Line Daily" is a working name for testing and hasn't been cleared as a trademark.

## Build check
Run `python3 build.py` before every push. It fails with a file:line list if any name in `retired-names.txt` appears outside `archive/`.
